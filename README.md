## 🚀 Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/yourusername/networking-hub-bot.git
   cd networking-hub-bot
   ```

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv venv
   ```

3. **Активируйте виртуальное окружение:**
   ```bash
   # Для Linux/Mac:
   source venv/bin/activate
   
   # Для Windows:
   venv\Scripts\activate
   ```

4. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

5. **Создайте файл с переменными окружения:**
   ```bash
   # Для Linux/Mac:
   cp .env.example .env
   
   # Для Windows:
   copy .env.example .env
   ```

6. **Отредактируйте .env файл:**
   ```env
   BOT_TOKEN=your_bot_token_here
   ```

## ⚙️ Настройка

### Получение токена бота:
1. Напишите @BotFather в Telegram
2. Отправьте команду /newbot
3. Следуйте инструкциям для создания нового бота
4. Скопируйте полученный токен в файл .env

### Первоначальная настройка:
- При первом запуске автоматически создается администратор с вашим ID
- Все данные сохраняются в папке `data/`

## 🏃 Запуск

```bash
python bot.py
```

Бот использует московское время (Europe/Moscow) для всех временных меток.

## 🎲 Система конкурсов

### Создание конкурса:
1. Администратор вводит название
2. Указывает время начала и окончания (Московское время)
3. Загружает фото (опционально)
4. Бот генерирует уникальную реферальную ссылку

### Формат времени:
```
21:11 06.08.2025
```

### Участие в конкурсе:
1. Пользователь переходит по реферальной ссылке
2. Автоматически получает 1 билет
3. Приглашая друзей, получает дополнительные билеты
4. Приглашенный друг также получает 1 билет

### Завершение конкурса:
- Автоматическое определение победителя случайным выбором
- Отправка уведомлений всем участникам
- Отправка детального отчета администраторам
- Автоматическое удаление завершенного конкурса

## 🔄 Автоматизация

Бот автоматически:
- Проверяет завершенные конкурсы каждые 10 секунд
- Подводит итоги через минуту после окончания конкурса
- Отправляет уведомления победителю и администраторам
- Удаляет завершенные конкурсы и их фото

## 🔒 Безопасность

✅ Все токены и ключи хранятся в переменных окружения  
✅ Данные пользователей сохраняются в JSON файлах  
✅ Администраторы назначаются только по ID  
✅ Файлы с данными не попадают в git репозиторий  

## 🐛 Возможные проблемы и их решение

### Бот не запускается:
- Проверьте наличие токена в .env файле
- Убедитесь, что все зависимости установлены
- Проверьте права на запись в директорию data/

### Не приходят уведомления:
- Проверьте, что пользователь не заблокировал бота
- Убедитесь в правильности временных меток конкурса
